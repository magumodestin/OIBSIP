# FITFORCE – Gym Landing Page

Oasis Infobyte SIP · Web Development & Designing · Level 1 · Task 1

A static, responsive landing page for a fictional gym brand, **FITFORCE**.

## Features
- Sticky navigation bar with 6 links (Home, Features, Classes, Trainers, Pricing, Contact)
- Hero section: headline, subheadline and two call-to-action buttons
- Content sections: Why Choose FitForce, Classes, Trainers, Member testimonials, Pricing
- Footer with company, support and social links
- One consistent red / black colour palette
- Responsive layout (CSS Flexbox and Grid) that works at mobile widths
- Intentional spacing with `box-sizing: border-box` and set padding/margins
- Clear typography with heading and body sizes

## Tech stack
HTML5, CSS3 (no JavaScript, as required by the task)

## Run it
Open `index.html` in a browser. Images load from Unsplash, so an internet connection is needed.

# Personal Portfolio

Oasis Infobyte SIP · Web Development & Designing · Level 1 · Task 2

A responsive personal portfolio website that showcases my skills, projects, badges and contact details.

## Features
- Animated loading screen: my name fills up while a countdown timer runs, then the portfolio opens
- Hero section with my name, role title, photo, and GitHub / LinkedIn / email links
- About Me section
- Skills grid with icons, animated proficiency bars and languages spoken
- Projects section: project cards with title, description, tech tags, Live Demo and GitHub links
- Achievements section with course badges (click any image to enlarge it)
- Contact section: email, LinkedIn and GitHub
- Dark / light theme toggle
- Smooth-scroll navigation with the current section highlighted
- Fully responsive, with a hamburger menu on small screens
- Consistent colour scheme and Poppins font throughout

## Tech stack
HTML5, CSS3, JavaScript (vanilla), Font Awesome icons, Google Fonts

## Project structure
```
index.html        loading screen (opens first)
loading.css
loading.js
portfolio.html    main portfolio page
portfolio.css
portfolio.js
imgs/             profile photo, project screenshots, badges
```

## Run it
Open `index.html`. After the 5-second loading animation it redirects to `portfolio.html`. Open `portfolio.html` directly to skip the animation.
